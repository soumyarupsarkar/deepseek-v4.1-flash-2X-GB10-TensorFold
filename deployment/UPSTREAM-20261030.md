|---|---|

Adapted from [koniaik's Mia PR 76](https://github.com/MiaAI-Lab/DeepSeek-v4.1-Flash-1017-2x-DGX-Sparks/pull/76), with a local Responses relay and output-clock handling. |

| Cache metrics | Report cached prompt tokens in aggregate health/completion counters and Prometheus metrics; preserve per-alias context limits. Adapted from Mia patch 0036 and its credits to manuel1618 and juliankang4. |
| Drafting under constraints | Verify speculative paths against the existing xgrammar matcher, including hypothetical prefixes and forced reasoning closes. Inspired by [nuk3s's Mia PR 85](https://github.com/MiaAI-Lab/DeepSeek-v4.1-Flash-1017-2x-DGX-Sparks/pull/85), head `1c28eb4d7f31b5d7a31e912af2df6c9cd971b85b`. The existing xgrammar compiler and JSON/schema/tool/regex/choice/EBNF support remain in use. |

The constrained decoder previews a candidate prefix, samples only allowed tokens
at the same keyed positions as ordinary decoding, then rolls back the hypothetical
matcher state. Only committed output advances lasting grammar state. Failed
previews and EOS are rolled back too. The bridge ABI is now version 2; build the
engine and bridge together. Constrained requests use ordinary decoding by default.
OpenAI Chat, Completions and Responses callers can opt in with `"draft": true`;
`"draft": false` explicitly selects ordinary decoding. The Anthropic adapter
does not forward this extension and keeps ordinary constrained decoding.
The nonnative backend continues using ordinary constrained decoding.
Combining a grammar or tool constraint with `ignore_eos: true` is rejected with
HTTP 400 before a stream opens, in both draft modes. The matcher cannot continue
after its terminating token; this also closes a preexisting ordinary-decoding
edge case.

The draft row budget, graph cache limit, 2.5 GiB host reserve and 2 GiB monitor
floor are unchanged. No disk KV caching or persistent host setting is added.

`tensorfold:prompt_tokens_cached_total` and `tensorfold:prefix_cache_hits_total`
count cached **tokens**, not requests. `tensorfold:prefix_cache_queries_total`
counts all prompt tokens. The health response exposes the same cached-token
total, so dashboards can separate cached work from newly computed prefill.

Pause client submissions. From the new serving checkout:

```bash
python3 cluster stop
python3 cluster check-host
```

Then, from the retained preceding checkout with its own unchanged local config:

```bash
python3 cluster start --variant stock
python3 cluster status
```

rebuild, host-journal copying or reboot is required. Do not run two owners on
the same GPU pair at once. To restore the host baseline instead of serving the
preceding version, stop after `check-host`.
